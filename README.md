# ai-orchestration-tools (public)

Free, open AI orchestration tools: a task router plus small tested Python utilities.

- `router.py` - routes a task to deterministic code, local compute, web research, parallel agents, Kaggle GPU, or GitHub Actions ($0 cost guard).
- `tools/` - csv_analysis, fetch_and_extract, dedupe, verify_sources, monitor, report (Python stdlib + pandas).
- Workflows in `.github/workflows/` are manual-trigger demos that run on GitHub-hosted runners.
- `data/iris.csv` - classic public-domain Iris dataset for the batch data demo.

No secrets, no personal data. Use freely.
